# GrowthRouter

Find the people asking for what you built.

GrowthRouter finds people asking for your product on Reddit, X, Hacker News, YouTube, and Google, and drafts replies in your voice.

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
